# Правила проекта

Зомби-режим для Roblox. Пользователь общается по-русски, отвечать ему по-русски.

## Ориентиры по духу игры (всегда сверяться с ними)

1. **Counter-Strike 1.6 Zombie Mod / Zombie Plague** - раунды, заражение, HUD жёлто-оранжевый (255, 160, 0), amx-меню с цифрами, сообщения сервера с тегом в чате, голосование за карту.
2. **Garry's Mod** - физика тел (рэгдолл), звуки ударов тел, пинаемые пропы, дурачество.
3. **Forsaken (Roblox)** - мрачная подача, лобби между раундами, напряжённая атмосфера.

Визуально - старый Роблокс: простые блоки, ночь, туман.

## Как писать код

- Комментарии в коде только там, где пользователю можно что-то поменять. Всё настраиваемое выносить в `src/shared/Config/*`, комментарии там на русском, коротко.
- Тексты для игроков - в `src/shared/Strings.luau`, на русском и английском. Писать живо и коротко, как на старых серверах CS. Без канцелярита, без эмодзи, без "добро пожаловать в увлекательный мир".
- Ассеты (звуки, анимации, модели) - только бесплатные и без чужих авторских прав: встроенные `rbxasset://` или из Creator Store. Анимации берём готовые.
- Не трогать Baseplate и Workspace пользователя. Карта из Workspace используется как есть.
- Раскладывать по папкам: сервер - `src/server/Services`, клиент - `src/client/Controllers`, общее - `src/shared`.
- Всё должно быть стабильно играбельным: таймауты на все ожидания, защита от выхода игрока посреди действия, проверка данных от клиента на сервере.

## Проверка перед коммитом

```
stylua src
selene src                 # roblox.yml генерируется: selene generate-roblox-std
rojo sourcemap default.project.json -o sourcemap.json
luau-lsp analyze --platform=roblox --definitions=@roblox=globalTypes.d.luau --sourcemap=sourcemap.json src
rojo build -o build/prime.rbxl
```
