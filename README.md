# prime

Зомби-режим для Roblox в духе старого CS 1.6 Zombie Mod, с физикой тел как в Garry's Mod и мрачной подачей как в Forsaken.

Сейчас готова основа: лобби, появление через вентиляцию, голосование за карту, цикл раундов. Самих зомби пока нет, раунд просто идёт по таймеру и возвращает всех в лобби.

## Что уже работает

- **Лобби** - бетонная техкомната канализации: канал с водой, трубы, лампы дневного света (одна мигает), ящики и бочки, которые можно пинать, табло-терминал с состоянием сервера.
- **Появление через вентиляцию.** Игрок появляется в темноте под звуки трубы, потом его тело выплёвывает из квадратного люка на стене прямо в лобби. Крышка люка распахивается и хлопает обратно, над люком мигает красная лампа. Тело летит тряпкой и шлёпается со звуками ударов, потом игрок встаёт.
- **Рэгдолл.** В лобби на `R` можно упасть самому (на бегу спотыкаешься вперёд). После смерти тело тоже падает тряпкой.
- **Голосование за карту** как amx-меню из CS: цифры `1-9`, `0` закрыть, `M` открыть снова. На телефоне пункты нажимаются пальцем.
- **Цикл:** ждём игроков -> голосование -> раунд на выбранной карте -> все обратно в лобби через вентиляцию.
- **Первая карта - Baseplate.** Берётся тот, что уже лежит у тебя в Workspace, код его не двигает и не удаляет.
- **HUD как в CS 1.6:** здоровье слева внизу, таймер по центру внизу, статус сверху, сообщения сервера в чате с тегом `[ZM]`.
- **Тексты на русском и английском,** язык выбирается сам по настройкам игрока.

## Как подключить

Проект собирается через [Rojo](https://rojo.space) - он синхронизирует файлы отсюда в Roblox Studio.

1. Поставь Rojo. Проще всего через [Rokit](https://github.com/rojo-rbx/rokit): в папке проекта выполни `rokit install`, версии уже прописаны в `rokit.toml`. Ещё вариант - расширение "Rojo" для VS Code.
2. Поставь плагин Rojo в Studio: `rojo plugin install`.
3. В папке проекта запусти `rojo serve`.
4. Открой свой плейс с Baseplate, вкладка Plugins -> Rojo -> Connect.
5. Жми Play.

Rojo трогает только папки `ReplicatedStorage/Shared`, `ServerScriptService/Server` и `StarterPlayer/StarterPlayerScripts/Client`. Workspace и Baseplate он не трогает.

Проверить с несколькими игроками: вкладка Test -> Clients and Servers -> 2 игрока -> Start.

## Советы по настройке плейса

- Game Settings -> Avatar -> **R6**. Так ближе к старому Роблоксу, и рэгдолл на R6 выглядит смешнее. R15 тоже работает.
- Lighting -> Technology -> **Future**. Тогда лампы в лобби дают тени.

## Где что лежит

```
src/
  shared/                  -> ReplicatedStorage.Shared (видят и сервер, и игроки)
    Config/                <- все настройки, править тут
      GameConfig           время лобби/голосования/раунда, минимум игроков, язык
      MapConfig            список карт
      LobbyConfig          размеры, цвета и позиция лобби
      SpawnConfig          вылет из вентиляции: сила, время, камера
      RagdollConfig        рэгдолл: клавиша, время, пороги звуков ударов
      SoundConfig          все звуки
      LightingConfig       освещение в лобби и на картах
    Strings                все тексты (русский и английский)
    GameState              общее состояние игры (фаза, таймер, карта, голоса)
    Remotes                RemoteEvent'ы
    SoundPlayer            проигрывание звуков
  server/                  -> ServerScriptService.Server
    Main                   запуск всех сервисов
    Lobby/                 постройка лобби и вентиляции кодом
    Services/
      LobbyService         лобби, ящики, границы комнаты
      SpawnService         очередь на вылет из вентиляции
      RagdollService       включение и выключение рэгдолла
      MapService           загрузка карт и точки появления
      VoteService          голосование
      RoundService         цикл раундов
      NotifyService        сообщения игрокам
    Util/CollisionGroups   группы столкновений
  client/                  -> StarterPlayer.StarterPlayerScripts.Client
    Main                   запуск всех контроллеров
    Controllers/
      HudController        HUD в стиле CS
      VoteController       amx-меню голосования
      BoardController      табло и таблички в лобби
      VentController       камера и физика вылета, крышка люка
      RagdollController    падение на R, вставание
      ImpactController     звуки ударов тел и ящиков
      AmbienceController   свет, эхо, мигающая лампа, шум воды
      NotifyController     сообщения в чат и по центру экрана
    UI/                    цвета, шрифты, хелперы интерфейса
```

В коде комментарии стоят только там, где можно что-то поменять. Всё, что стоит крутить, вынесено в `src/shared/Config`.

## Как добавить карту

1. Собери карту в одну Model и положи в `ServerStorage > Maps` (папку создай сам).
2. Внутри модели сделай папку `Spawns` и накидай туда парты - это точки появления.
3. Добавь запись в `src/shared/Config/MapConfig.luau` с `Source = "ServerStorage"`. Пример там уже есть закомментированный.

## Звуки

Сейчас стоят встроенные звуки Roblox (`rbxasset://sounds/...`). Они есть у всех и без авторских прав, подобраны по высоте тона так, чтобы удары звучали как тело.
Оригинальные звуки Garry's Mod принадлежат Valve, их загружать нельзя. Свои ID вставляются в `SoundConfig.luau`, там же подписано, что где играет. Если какой-то звук не загрузится, игра просто пропустит его.

## Анимации

Своих анимаций пока нет, используются стандартные. Когда дойдём до зомби, возьмём бесплатные из Creator Store.

## Для разработки

- `stylua src` - форматирование
- `selene src` - линтер (перед первым запуском: `selene generate-roblox-std`)
- `rojo build -o build/prime.rbxl` - собрать плейс файлом
